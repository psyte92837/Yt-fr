# Протокол персонажа `lumen.char` v1

Это формат, в котором Lumen Studio получает персонажа для раздела «🎨 Анимация». Его может прислать встроенный AI Lumen (по описанию или по картинке), любой сторонний ИИ (ChatGPT, Gemini, Claude…) или другой пользователь Lumen («⧉ Копировать код»). Персонаж — это **один JSON-объект**. Все поля необязательные: чего нет в ответе, остаётся у героя, которого сейчас редактируют.

Код: `StudioChar.kt` (`StudioParts`, `StudioCharProto`), тесты: `StudioCharTest.kt`.

## Как получить персонажа от стороннего ИИ

1. В редакторе героя нажмите «🤖 Через другой ИИ». Lumen скопирует готовый запрос со схемой протокола.
2. Вставьте запрос в любой чат-бот. Если героя нужно повторить по картинке, отметьте «Я приложу картинку» и приложите её.
3. Скопируйте ответ целиком и нажмите в Lumen «📥 Вставить код или ответ». Markdown-блоки ```` ``` ````, текст вокруг JSON, проценты вместо долей и незнакомые значения допускаются: незнакомое пропускается, и Lumen показывает, что именно пропущено.

Если картинка сама будет героем («🧸 Картинка — сам герой»), сторонний ИИ возвращает ещё и поле `face` с координатами глаз и рта. Встроенный AI делает то же по кнопке «✨ AI найдёт глаза и рот».

## Поля

| Поле | Значение |
|---|---|
| `format` | `"lumen.char"` |
| `v` | `1` |
| `name` | Имя одним словом: буквы, цифры, `_`, `-`, до 20 символов. Пробелы станут `_` |
| `base` | Ближайшая заготовка: `fox cat bear robot owl kid prof blob dog rabbit panda penguin frog alien dino girl`. Задаёт подпись, голос по умолчанию и тон |
| `persona` | Характер и манера речи, до 300 символов. AI-сценарист пишет реплики героя в этом характере |
| `voice` | `"f"`, `"m"`, `""` (авто) или имя голоса Edge (`ru-RU-SvetlanaNeural`) |
| `pitch` | Сдвиг тона в Гц, от −30 до 40. Если поля нет, тон берётся по `base` |
| `rate` | Сдвиг темпа в %, от −20 до 30, добавляется к общему темпу Studio |
| `parts` | Детали рисованного героя, см. ниже |
| `face` | Точки лица на своей картинке, см. ниже |

### `parts`

Голова и тело у героя — одно целое; ноги, руки и жесты рисуются всегда.

| Поле | Значения |
|---|---|
| `body` | `round`, `box` (коробка робота) |
| `top` | `none ears_pointy ears_fox ears_round ears_dark ears_long ears_floppy ears_mouse tufts horns antenna antennae spikes bumps grey_sides pigtails`. `bumps` — глаза лягушки на макушке; `grey_sides` и `pigtails` красятся цветом `hair` |
| `hair` | `none`, `short` (чёлка), `curly` (кудри) |
| `front` | `belly`, `pale`, `penguin`, `screen`, `clothes`, `none`. `clothes` — человек: низ тела и рукава цвета `clothes`, кисти цвета `main` |
| `eyes` | `round`, `dot`, `sleepy`, `visor` (экранные глаза и рот робота, без бровей) |
| `eyeMark` | `none`, `disc` (совиные диски), `patch` (пятна панды) |
| `nose` | `none`, `dot`, `pink`, `beak` |
| `tail` | `none`, `spikes`, `fluffy`, `thin`, `puff` |
| `acc` | До 4 из `glasses hat cap bow crown headphones tie scarf` |
| `muzzle`, `whiskers`, `cheeks` | `true` / `false` |
| `colors` | `main` (тело или кожа), `clothes`, `hair`, `limbs` (руки), `feet` — `"#RRGGBB"`, `"#RGB"` или простое имя (`red`, `blue`…); `""` у `limbs` и `feet` означает «авто» |
| `width` | 0.8–1.25 |
| `height` | 0.85–1.2 |
| `eyeSize` | 0.7–1.5 (1 — обычные пропорции) |

### `face` (только для своей картинки)

Координаты задаются в долях ширины и высоты картинки от левого верхнего угла, от 0 до 1. Можно писать и в процентах: `60` или `"60%"`.

| Поле | Значение |
|---|---|
| `eyeL`, `eyeR` | `[x, y]` или `{"x":…, "y":…}` — центры глаз. Порядок не важен: левым считается глаз ближе к левому краю |
| `mouth` | `[x, y]` — центр рта |
| `mouthW` | Ширина рта в долях ширины картинки, от 0.03 до 0.5 |

Без поля `face` герой-картинка тоже работает: дышит, подпрыгивает на репликах и наклоняется по эмоции, но не моргает и не открывает рот. Цвет век Lumen берёт с картинки, чуть выше глаз.

## Пример

```json
{"format":"lumen.char","v":1,"name":"Фокси","base":"fox","persona":"хитрая, говорит коротко и с иронией",
 "voice":"f","pitch":10,"rate":0,
 "parts":{"body":"round","top":"ears_fox","hair":"none","front":"belly","eyes":"round","eyeMark":"none",
  "nose":"dot","tail":"fluffy","acc":["scarf"],"muzzle":true,"whiskers":false,"cheeks":true,
  "colors":{"main":"#F28C38","clothes":"#5B6475","hair":"#6B4226","limbs":"","feet":""},
  "width":1,"height":1,"eyeSize":1}}
```

## Совместимость

- Новые поля и значения добавляются только в новой версии `v`. Если `v` новее приложения, Lumen берёт то, что понимает, и предупреждает.
- Код героя-картинки переносит детали и точки лица, но не саму картинку. На другом устройстве такой герой рисуется из `parts`.
