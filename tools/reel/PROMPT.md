# Lumen Reel: промпт для монтажа роликов с драйвом

Скрипт `reel.py` делает всё сам: вырезает паузы, распознаёт речь, накладывает субтитры по словам, моушн-плашки, зум на склейках, SFX и бит, сводит громкость к −14 LUFS. Claude не пишет код. Он правит текст расшифровки и заполняет короткий `plan.json`, это около 1–2 тыс. токенов вывода на ролик.

## Как экономить (важно)
1. **Новая сессия на каждый ролик.** Длинная переписка повторно отправляет весь контекст на каждом шаге.
2. **Окружение без подключённых репозиториев.** CLAUDE.md проекта Lumen добавляет около 10 тыс. токенов к каждому шагу. Скрипт скачивается по публичной ссылке, репозиторий не нужен.
3. **Модель Sonnet.** Задача шаблонная, Opus для неё избыточен и тратит лимит в несколько раз быстрее.
4. **Без промежуточных вопросов.** Прикрепите видео и вставьте промпт целиком, тогда сессия уложится в 6–8 шагов.

## ПРОМПТ (скопировать целиком, прикрепить видео)

```
Смонтируй вертикальный ролик с драйвом из прикреплённого видео строго по шагам. Экономь токены: не читай reel.py, не пиши свой код, объединяй команды в один вызов Bash, не смотри кадры, кроме одного sheet.jpg, ответ в конце в 3 строки.

1) Bash (одной командой; VIDEO = путь к прикреплённому файлу):
   mkdir -p ~/reel && cd ~/reel && curl -sSLO https://raw.githubusercontent.com/psyte92837/Yt-fr/main/tools/reel/reel.py && python3 reel.py setup && python3 reel.py transcribe "VIDEO" ru
2) Перепиши reel_work/transcript.txt (Write), сохранив формат "нач-кон | текст" и времена:
   исправь ошибки распознавания (имена, бренды, числа цифрами, пунктуация, пропущенные слова по смыслу), мусорную строку сделай пустой после "|".
3) Запиши reel_work/plan.json по схеме ниже: 6–12 карточек по смыслу речи, каждые 3–5 с что-то появляется, первая — title-хук (≤3 с), последняя — end с призывом. emphasis: 6–12 ключевых слов (числа, бренды, выгоды).
4) Bash: cd ~/reel && python3 reel.py preview "VIDEO"  → посмотри reel_work/sheet.jpg один раз. Наложения или не те моменты исправь в plan.json (без повторного превью).
5) Bash: cd ~/reel && python3 reel.py render "VIDEO" ~/reel/Reel.mp4  → отправь файл через SendUserFile.

СХЕМА plan.json (все поля, кроме cards, необязательны):
{"emphasis":["слово",...],            // подсветка жёлтым + зум
 "fit":"cover"|"blur",                // blur — для горизонтального исходника
 "music":true,"bpm":124,"pad":0.09,   // pad — сколько тишины оставить у фраз (меньше = быстрее)
 "accent":"#FFD60A","accent2":"#7C5CFF",
 "cards":[  // в порядке появления; якорь = слово/начало слова/фраза из расшифровки,
            // "слово#2" — второе вхождение, "@12.5" — секунда исходника, "@-1.5" — от конца,
            // "+1.5" (только until) — через 1.5 с после at. Ищется по порядку после предыдущей карточки.
  {"type":"title","at":"@0","until":"+2.5","kicker":"МАЛЕНЬКАЯ СТРОКА","lines":["ХУК","В 2 СТРОКИ"]},
  {"type":"pill","at":"слово","until":"слово","text":"ТЕКСТ","color":"accent|violet|red|green|white|pink|dark|#RRGGBB","pos":"top|bottom"},
  {"type":"checklist","items":[["Пункт","якорь"],...],"until":"якорь"},          // 2–4 пункта, галочки по словам
  {"type":"tags","items":[["ТЕГ","якорь"],...],"until":"+0.6"},                  // перечисления, 3–8 тегов
  {"type":"button","at":"подписыв","text":"ПОДПИСАТЬСЯ","done":"✓ ВЫ ПОДПИСАНЫ"},// клик курсором
  {"type":"compare","at":"якорь","reveal":"якорь","final_at":"якорь","final":"$3–10",
     "left":["БЫЛО","$20","в месяц"],"right":["СТАЛО","$3","в месяц"],"until":"якорь"}, // зачёркивание цены
  {"type":"platforms","items":[["Instagram","якорь","pink"],["YouTube","якорь","red"]]},
  {"type":"end","at":"@-2","lines":["ПОДПИШИСЬ","НА КАНАЛ"]}]}
Позиции: top/upper — верх (над лицом), bottom — под субтитрами; плашка в той же позиции убирает предыдущую.
Тексты плашек КАПСОМ, ≤18 символов в строке; не дублируй дословно субтитры — плашка = суть/выгода/число.
```

## Без ИИ (0 токенов)
`python3 reel.py auto IN.mp4 OUT.mp4`: распознавание, авто-план (хук из первых слов, числа плашками, финал) и рендер. Тексты будут сырыми, это быстрый черновик.

## Сколько это стоит
| Шаг | Токены |
|---|---|
| Системный промпт и инструменты, 6–8 вызовов (почти всё из кэша) | ~90–130 тыс. входа |
| Расшифровка ролика ~1 мин | ~1,5 тыс. |
| Правленая расшифровка и plan.json (вывод) | ~1,5–2,5 тыс. |
| sheet.jpg | ~1,5 тыс. |
| **Итого на ролик** | **~100–140 тыс., из них ~95% чтения кэша** |

Первый ролик, собранный вручную, занял около 600 тыс. токенов, то есть по этому промпту выходит в 4–6 раз меньше. Больше всего экономится на выводе: вместо ~15–20 тыс. токенов кода и отладки остаётся ~2 тыс., а вывод расходует лимит сильнее всего. Если оставить подключёнными репозитории Lumen и Opus, расход вырастет в 2–4 раза.

## Ограничения
- Время слов прикидывается по длине слова внутри участков речи, точность ±0,2 с.
- Распознаётся речь только из видео. Если в ролике одна музыка, расшифровка будет пустой: впишите текст строками вручную.
- Рендер 1 минуты занимает ~3 мин на 4 ядрах. Модель ~640 МБ скачивается один раз за сессию с GitHub (Hugging Face в облаке закрыт).
