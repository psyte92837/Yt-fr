# Тесты Lumen

Все тесты — JVM (`app/src/test/java/org/schabi/newpipe/lumen/`), запускаются в CI: `./gradlew testDebugUnitTest`.
Эмулятора в CI нет, поэтому логика выносится в чистые файлы без Android и проверяется здесь.

| Вид | Что ловит | Файлы |
|---|---|---|
| Примеры (example-based) | точный результат функции на известных входах | `*Test.kt` по модулям (AudioEditTest, BoardTest…) |
| Свойства с состоянием (stateful property) | последовательности действий, о которых никто не подумал: сотни сидов × десятки шагов, инварианты после каждого шага, JSON туда-обратно | `AudioEditPropertyTest`, `BoardPropertyTest` |
| Фаззинг парсеров | падения на мусоре: ответы ИИ, ввод времени, обрезанные файлы проекта | `ParserFuzzTest` |
| Контракт манифестов | экран не в манифесте, intent-filter без exported, запреты Play Защиты, Студия без NewPipe | `ManifestContractTest`, `StudioSharedFilesTest` |
| Контракт ассетов | битые каталоги переводов, потерянные `{0}`, шрифт без лицензии OFL, каталог бесплатных ИИ | `AssetsContractTest` |
| Архитектурные правила | UI только кодом, ИИ только через Llm, нет ключей/трекеров/http, SPDX, чистые файлы без android.* | `ArchitectureRulesTest` |
| Живые | работает ли YouTube сейчас (только `-DlumenLive=1`) | `LiveYouTubeTest` |

Правила:
- Случайные тесты — с фиксированным сидом; сообщение об ошибке называет сид, шаги и вход, чтобы повторить.
- Новый чистый файл — добавить в `pureLogicDoesNotTouchAndroid`, если его логику тестируют на JVM.
- Новый парсер внешнего текста (ответ ИИ, ввод пользователя, файл на диске) — добавить в `ParserFuzzTest`.
- Новый экран — в манифест (блок `===== Lumen =====`); `ManifestContractTest` напомнит.
